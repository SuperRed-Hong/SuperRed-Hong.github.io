Profile

我是 Flynn Hong / 秋水（AutumnWater），主要做游戏程序，也参与玩法设计和视觉实现。我参与过 Ludum Dare、GMTK、CIGA 等 Game Jam 和独立游戏项目，也有作品发布到 TapTap。在“永远的三缺一制作组”中，我的主要职责是程序开发，经历横跨 Unity、Unreal Engine、玩法系统、UI/UX、Git 协作、UE 编辑器工具和技术美术 VFX。

我习惯先把系统拆开：对象、状态、数据来源、同步路径、失败情况、调试入口。这个习惯来自 Game Jam 的快速迭代，也来自 StageEditor 这类长期工具项目中反复遇到的数据一致性、编辑器事务、性能和协作问题。
