StageEditor.

Organize scenes with Stages, Acts, and Entities.

A Stage manages the lifecycle, an Act describes a scene state, and an Entity represents an object. DataLayers connect scene editing with runtime state changes.

  • DataLayer workflowImport, synchronization, status checks, and SceneOutliner integration.
  • Undoable editingA hierarchical Slate panel with drag-and-drop editing and Undo / Redo.
  • Separate Runtime / Editor modulesBlueprint event interfaces; no editor dependencies in the runtime module.
View source ↗Documentation ↗

DataLayer features require World Partition. See the repository for versions and installation.
