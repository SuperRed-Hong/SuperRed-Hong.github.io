UNREAL ENGINE 5.6C++ / SLATEMIT LICENSE

StageEditor.

用「舞台、幕、实体」组织场景。

Stage 管理整体生命周期，Act 描述一种场景状态，Entity 承载具体对象。通过 DataLayer 连接场景编辑与运行时状态切换。

  • DataLayer 工作流导入、同步、状态检查与 SceneOutliner 集成。
  • 编辑操作可撤销Slate 层级面板、拖放编辑与 Undo / Redo。
  • Runtime / Editor 分离Blueprint 事件接口；运行时模块不依赖编辑器。
